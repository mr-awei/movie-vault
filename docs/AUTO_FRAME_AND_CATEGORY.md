# 截帧兜底与自动分类

> 影海（Yinghai / Movie Vault）：本地影视收藏管理工具。仅用于管理用户本地自有影片，不传播、不分发任何内容。
>
> 本文描述封面解析、ffmpeg 截帧与自动分类的当前实现；参数与阈值以 `src/main/lib/images.ts`、`src/main/lib/reconcile.ts` 为准。

## 1. 为什么需要截帧兜底

封面优先来自数据源（MovieDB / OMDb / OpenLibrary / JustWatch / 维基百科）。当某部影片在数据源中没有海报，或用户处于离线状态时，应用会用 ffmpeg 从本地视频采样画面生成封面与预览图，避免出现空白卡片。

## 2. 封面解析优先级

`resolvePoster()` 按**媒体库配置的封面优先级链**（`library.imagePriority`）依次尝试：

| 顺序 | 来源 | 说明 |
| --- | --- | --- |
| 1 | `manual` | 用户手动指定的封面（如「设为封面」） |
| 2 | `sidecar` | 视频同目录下的同名图 / 目录同名图 / 通用名图（`poster` `cover` `folder` 等，支持 jpg / jpeg / png / webp / bmp） |
| 3 | 数据源 | MovieDB / OMDb / OpenLibrary / JustWatch / 维基百科 返回的海报（下载并本地缓存） |
| 4 | `ffmpeg` | 从视频画面截帧生成封面 |
| 5 | `placeholder` | 内置占位图（渐变 + 首字母），保证卡片不空白 |

> 列表页、详情页、相关推荐使用同一优先级链，避免「列表有海报、详情是占位」的不一致。

## 3. 截帧策略

### 3.1 预览集（`generatePreviewSet`）
一次调用完成「封面 + 预览集」：

| 步骤 | 策略 |
| --- | --- |
| 封面候选 | 随机采样 **12** 个时间点，逐帧评估质量，取最优帧 |
| 预览候选 | 随机采样 **22** 个时间点，评估后取前 **15** 张（`PREVIEW_COUNT`） |
| 采样范围 | 跳过片头约 5% 与片尾约 5%，起点不早于第 5 秒；时长缺失时按 600s 估算 |
| 并发 | 截帧与评分各限制为 **4** 路并发 |
| 超时 | 单次截帧 **30s** 超时，超时强制结束子进程 |
| 兜底 | 封面无有效候选但预览有 → 用最优预览帧作为封面 |

### 3.2 单帧封面（`generateFrame`）
用于解析优先级链中的「ffmpeg」分支（扫描富集阶段以 `allowFfmpeg` 控制）：

- 使用 ffmpeg `thumbnail` 滤镜自动挑选最具代表性的一帧；
- 分析帧数 `n = clamp(dur / 30, 100, 200)`，兼顾短片与超长片；
- 输出宽度固定 `480`，控制缓存体积。

### 3.3 帧质量评估
将候选帧缩放到 **8×8 灰度** 后计算统计量：

```
ok = (25 ≤ 平均亮度 ≤ 230) 且 (方差 ≥ 400)
```

- 平均亮度阈值剔除纯黑 / 纯白帧；
- 方差阈值剔除模糊、画面过于单调的帧；
- 按方差降序排序，方差最高者优先；**若没有任何候选通过，则退化为方差最高者兜底**。

### 3.4 失败处理与冷却
- 损坏文件、超时导致的截帧失败会写入 `frameFailedAt` 时间戳；
- 批量任务在冷却期内（约 7 天）跳过该文件，避免反复在同一个坏文件上卡住；
- 每轮批量补齐的后台截帧有数量上限（200 部），避免大库一次拉满 CPU。

### 3.5 缓存与文件命名

均位于海报缓存目录：

| 文件 | 用途 |
| --- | --- |
| `<videoId>.jpg` | 封面 |
| `<videoId>_preview_<n>.jpg` | 预览集第 n 张 |
| `<videoId>_cover_cand_<n>.jpg` | 封面临时候选（用完即删） |
| `<videoId>_preview_cand_<n>.jpg` | 预览临时候选（用完即删） |

封面文件被覆盖但路径不变时，渲染层通过缓存版本号（`?v=N`）强制刷新，避免看到旧图。

## 4. 自动分类

当影片所在媒体库**没有配置 Excel 片单**（或影片未被片单覆盖）时，应用按数据源返回的类型自动归类：

- 有条目元数据（`meta.genres` 非空）→ 归入 `【数据源】类型1·类型2` 形式的自动分类（如 `【MovieDB】剧情·悬疑`），排序权重 `9000`；
- 无元数据 → 归入「未分类」（权重 `0`）；
- 自动分类**不会覆盖**片单已定义的分类，`kind` 仍保持匹配状态。

实现位置：`src/main/lib/reconcile.ts`（未配置片单分支）。类型标签会先经通用清洗器去掉数字后缀、括号与纯分隔符。

## 5. 参数速查

| 参数 | 值 | 位置 |
| --- | --- | --- |
| 封面候选采样数 | 12 | `images.ts` |
| 预览候选采样数 | 22 | `images.ts` |
| 预览图数量 `PREVIEW_COUNT` | 15 | `images.ts` |
| 采样头尾跳过比例 | 各 5% | `images.ts` |
| 采样起点下限 | 5s | `images.ts` |
| 截帧并发 | 4 | `images.ts` |
| 单次截帧超时 | 30s | `images.ts` |
| 质量阈值（亮度） | 25 ~ 230 | `images.ts` |
| 质量阈值（方差） | ≥ 400 | `images.ts` |
| 单帧分析帧数 | `clamp(dur/30, 100, 200)` | `images.ts` |
| 单帧输出宽度 | 480 | `images.ts` |
| 每轮后台截帧上限 | 200 部 | `ipc.ts` |
| 失败冷却期 | 约 7 天 | `ipc.ts` |
