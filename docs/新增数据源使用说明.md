# 新增数据源 · 开发者指南

> 影海（Yinghai / Movie Vault）：本地影视收藏管理工具。仅用于管理用户本地自有影片，不传播、不分发任何内容。
>
> 面向研发：接入一个新的元数据来源需要改动哪些文件、遵循哪些约定。示例以新增 `newsrc` 为例。

## 0. 约定

- 每个数据源是一个独立模块，统一导出 `fetchXxxDetail(query, settings, onError?, manual?)` 与「是否已配置」判定函数；
- 所有出网请求**必须**走 `src/main/lib/proxy.ts`，以保证代理设置生效；
- 返回值统一为 `MovieMeta | null`，不得抛异常给调用方；
- 描述性文案一律走 i18n，品牌名（如 `MovieDB`）固定英文、不进 i18n。

当前内置源：`moviedb`（MovieDB / TMDb）、`omdb`（OMDb）、`openlibrary`（OpenLibrary）、`justwatch`（JustWatch）、`wikipedia`（中文维基百科）。

---

## 1. 类型与默认值 —— `src/shared/types.ts`

1. 在 `SourceId` 联合类型中追加取值：

```ts
export type SourceId = 'moviedb' | 'omdb' | 'openlibrary' | 'justwatch' | 'wikipedia' | 'newsrc'
```

2. 若该源需要 API Key，在 `Settings` 中新增字段（如 `newsrcKey: string`），并在 `DEFAULT_SETTINGS` 中给出默认值 `''`。

> `SourceId` 是联合类型，漏改任何一处都会在 `npm run typecheck` 阶段直接报错。

## 2. 抓取实现 —— `src/main/lib/newsrc.ts`

新建模块并导出：

```ts
export async function fetchNewSrcDetail(
  query: MovieQuery,          // 已由 extractMovieQuery 清洗过
  settings: Settings,
  onError?: (msg: string) => void,
  manual?: boolean
): Promise<MovieMeta | null>

export function hasNewSrcKey(settings: Settings): boolean
```

实现要求：

- 未配置 Key 时直接返回 `null`（不要发起请求）；
- 请求统一走 `lib/proxy.ts`；
- 解析结果需填充 `uid` / `externalId` / `title` / `genres` / `actors` 等 `MovieMeta` 字段，并设置 `source: 'newsrc'`、`parseVer: 2`、`fetchedAt`；
- 类型标签先经 `cleanGenreName()` 清洗；
- 封面优先返回可下载的图片地址（由上层负责下载与缓存）。

## 3. 接入调度 —— `src/main/lib/fetch-meta.ts`

三处改动：

1. `DEFAULT_SOURCE_ORDER` 加入 `'newsrc'`（决定推荐降级顺序）。
2. `auto` 降级循环中加入分支，覆盖六种状态：未配置 / 本轮禁用 / 尝试 / 命中 / 无结果 / 网络失败；命中即 `return { detail, source: 'newsrc' }`。
3. 单源调试分支新增 `if (mode === 'newsrc') { ... }`。
4. 新增 `NEWSRC_CONSECUTIVE_LIMIT = 3`，用于「连续网络失败自动熔断本轮」。

事件回调必须按既有格式推送，UI 才能实时展示降级过程：

```ts
onEvent?.({ code, src: 'newsrc', status: 'trying' | 'hit' | 'skipped' | 'no-result' | 'network-failed', detail?: string })
```

## 4. 设置页 —— `src/renderer/src/components/SettingsModal.tsx`

三处硬编码需同步：

| 位置 | 改动 |
| --- | --- |
| `SOURCE_LABELS` | 加 `newsrc: 'NewSrc'`（品牌名固定英文） |
| `ALL_SOURCE_ORDER` | 加入 `'newsrc'` |
| `apiRequired` | 若需要 Key，改为 `src === 'moviedb' \|\| src === 'omdb' \|\| src === 'newsrc'`，并在下方新增对应 Key 输入框（参考 `movieDbKey` / `omdbKey`） |

## 5. 国际化 —— `src/shared/i18n/locales/zh-CN.ts` 与 `en-US.ts`

新增以下键（`cost` 可复用 `settings.source.free`，无需逐源写）：

```ts
'settings.source.newsrc.desc': '...',
'settings.source.newsrc.risk': '无风险',
'settings.source.newsrc.tier': '补充',
// 若需要 Key，再加：
'settings.source.newsrc.steps': '1. ...\n2. ...\n3. 粘贴到上方「NewSrc 密钥」框，保存设置后即可使用。'
```

`SettingsModal` 会按 `customSourceOrder` 自动渲染卡片（描述、风险、层级、是否需 Key、「如何获取 API Key」步骤与复制链接按钮），无需手写卡片组件。

## 6. 验证清单

- [ ] `npm run typecheck` 全绿（漏改 `SourceId` 相关位置会直接报错）。
- [ ] 设置页出现新卡片，可拖拽排序、可禁用。
- [ ] 单源模式选择 `newsrc` 能正常抓取。
- [ ] `auto` 模式下按顺序出现在正确位置，降级日志正常。
- [ ] 缺 Key 时显示「需 API Key」且不发起请求。
- [ ] 关闭该源后，详情抓取与海报抓取都不再尝试它。
- [ ] 中英文文案均完整。
