# 通用影片评分与简介规范

> 本规范是影海片单（Excel）的**唯一权威撰写标准**，用于统一每部影片的分类、评分与简介风格。
> 既可直接阅读，也可整份粘贴给 AI，让它按同一口径批量生成 / 校对片单。
>
> 设计取向：**去个人偏好、可复现、可校准**。评分不是"感觉给个数"，而是按固定维度加权计算；简介不是百科摘要，而是有结构、无剧透的可读文本。
> 影库越大，评分越稳定、越贴近你的真实观影判断。

## 一、评分标准

### 1.1 评分维度与建议权重（10 分制，保留两位小数）

| 维度 | 建议权重 | 观察点（打分依据） |
| --- | --- | --- |
| 剧作 / 编剧 | 16% | 结构完整性、逻辑自洽、人物弧光、对白质量、是否注水 |
| 导演与调度 | 14% | 叙事把控、场面调度、镜头语言、作者性、整体完成度 |
| 表演 | 14% | 主角与配角的可信度、层次感、情绪张力、群戏协调 |
| 摄影与美术 | 12% | 构图、光影、色彩、置景与服化道的完成度 |
| 剪辑与节奏 | 10% | 信息密度、张弛控制、是否拖沓或跳跃、章节结构 |
| 配乐与音效 | 10% | 主题旋律、音画配合、混音层次、声音设计 |
| 主题与思想性 | 8% | 议题深度、表达克制、是否留下余味与讨论空间 |
| 原创性与差异化 | 6% | 设定、视角、结构的独特性，是否避免同质化 |
| 制作规格与工业完成度 | 5% | 特效、动作设计、类型场面调度、成片质感 |
| 系列定位与口碑延续 | 5% | 是否为经典系列、续作与前作的一致性、系列内相对位置 |

**权重说明**

- 上表为**推荐默认值**，可按个人偏好调整（例如更看重表演与剧作，或更看重视听与场面）。
- 调整后权重之和必须为 100%，并在片单维护时保持一致，避免前后口径不一。
- 每项先独立打分，再加权合成；**不允许先给总分再倒推分项**。

**计算公式**

```
总分 = Σ(各维度得分 × 对应权重)
保留两位小数（第三位四舍五入）
```

### 1.2 参考分档（细化粒度的九档）

| 区间 | 等级 | 定义 | 决策含义 |
| --- | --- | --- | --- |
| 9.20 – 10.00 | 殿堂级 | 影史级作品，各维度均无可指摘，具备持续重看价值 | 必看，值得专门收藏 |
| 8.50 – 9.15 | 神作 | 至少一个维度达到年度甚至年代顶尖，整体高度统一 | 强烈推荐给所有人 |
| 7.80 – 8.45 | 优秀 | 完成度高、亮点明确，仅存个别瑕疵 | 主动推荐 |
| 7.00 – 7.75 | 良好 | 类型内合格偏上，娱乐性与完成度稳定 | 值得一看 |
| 6.30 – 6.95 | 及格 | 有明显短板，但整体可看，存在可取之处 | 片荒时可选 |
| 5.50 – 6.25 | 平庸 | 制作或叙事问题显著，亮点零散 | 非必要不看 |
| 4.50 – 5.45 | 较差 | 大部分维度失败，偶有局部亮点 | 不建议 |
| 3.00 – 4.45 | 差 | 创作或制作层面严重失败 | 避雷 |
| 0 – 2.95 | 极差 | 无法正常观看或存在硬性事故 | 明确避雷 |

> 档位区间刻意做得比"9 档均分"更细，原因见 1.7 评分通胀。

### 1.3 基准锚点（打分前先校准）

| 锚点类型 | 参考分值 | 用途 |
| --- | --- | --- |
| 公认影史经典 | 9.20 – 9.60 | 上限参照；不是每个年代都有 |
| 年度最佳 / 三大影展获奖级 | 8.50 – 9.15 | 优秀作品的天花板 |
| 类型片标杆（该类型最好的几部） | 7.80 – 8.45 | "这一类型能到什么程度" |
| 品质在线的院线商业片 | 7.00 – 7.75 | 大多数好片的落点 |
| 合格的流媒体 / 类型快消品 | 6.30 – 6.95 | 能看，但不值得专门找 |
| 有想法但执行失败 | 5.50 – 6.25 | 常见于野心过大的作品 |
| 制作事故级 | ≤ 4.45 | 极少出现 |

### 1.4 评分流程（五步法）

1. **对锚**：想清"它比哪个锚点更好/更差"，先定大致区间（如 7.8–8.5）。
2. **分项**：按 1.1 的十个维度逐项打分，每项写下至少一个具体依据。
3. **加权**：按公式合成，得到两位小数。
4. **回查**：用 1.6 的三问自检；若有答不上来的，回到第 2 步。
5. **落笔**：写入「推荐评分」列，并在需要时保留一句依据备注（可写在自己的备忘录，不必进片单）。

### 1.5 评分纪律

1. **不扎堆**：若 80% 的作品都在 8 分以上，说明标尺失效，需重新校准。
2. **不趋同**：不照抄 IMDb / 豆瓣；那是群体均值，片单是你的私人评价，允许差异但必须能自圆其说。
3. **不因题材加分**：喜欢某类型 ≠ 每个条目都该高分。
4. **不看热度**：票房、话题度、明星阵容、宣发规模都不构成加分项。
5. **不因单点封神**：一个惊艳镜头不足以撑起 9 分，必须整体成立。
6. **冷门作品保守**：样本极少的作品（很少有人看过）建议收敛到 7.0–8.0 区间，避免"小众滤镜"（对应 IMDb 加权平均的保守思路，见第二章）。
7. **复评有度**：重看后可修改，但同一部片短期内不要反复震荡。
8. **口径一致**：同一批片单内不要混用两套标准（例如有的按娱乐性打、有的按艺术性打）。

### 1.6 评分自检三问

1. 我给的分数，能否说出**至少两个具体依据**？
2. 同类型里更好的作品是否比它高？更差的是否比它低？
3. 若别人问"为什么是这个分"，我能否在**两句话内**解释清楚？

三问有一问答不上，回去重新打分。

### 1.7 常见评分偏差与矫正

| 偏差 | 表现 | 矫正方法 |
| --- | --- | --- |
| 评分通胀 | 全线 8 分以上，失去区分度 | 强制使用 1.2 的细档；回顾自己的低分作品是否被高估 |
| 分数紧缩 | 大多落在 6–7 分，好片也平平 | 允许 9 分以上存在，重看年度最佳与类型标杆 |
| 情感加分 | 观影时情绪好就高分 | 冷静 24 小时后再定档 |
| 题材滤镜 | 喜欢的类型一律偏高 | 只按维度打分，题材本身不加权 |
| 明星加分 | 因演员/导演名气给分 | 名气只影响"是否观看"，不影响"作品质量" |
| 从众 | 直接抄平台均分 | 平台分只用于校准区间，不用于最终分数 |
| 报复性低分 | 期待落差导致过低 | 与同类型作品横向比较后再定档 |

## 二、全网评分体系对照与借鉴

各平台的评分口径差异很大，理解它们有助于校准自己的标尺（**仅用于校准，不用于照抄**）。

| 平台 | 原始口径 | 特点与局限 | 映射到本规范 |
| --- | --- | --- | --- |
| **IMDb** | 用户 1–10 分；显示一位小数 | 采用**加权平均**（并非简单算术平均），并过滤异常 / 机器人投票；新片、冷门片票数少时分数波动大 | 借鉴其"票数少则保守"的思路；建议冷门片收敛在 7.0–8.0 |
| **豆瓣** | 用户 1–5 星，换算为 2–10 分（1 星 = 2 分）；显示一位小数 | 加权平均 + 异常账号过滤；文艺片与国产片样本偏多，类型偏见明显 | 只用于区间校准；不要直接搬分数 |
| **Metacritic** | Metascore 0–100（媒体加权，不同媒体权重不同，常取整）；User Score 0–10（分开显示） | 专业与大众两套分数分离，媒体权重不公开 | 借鉴"专业视角 vs 大众视角可分离"；对应本规范的"导演/剧作 vs 个人观感" |
| **Rotten Tomatoes** | 新鲜度 = 正面评价**比例**（不区分好到何种程度）；另有平均分（0–10）与观众爆米花指数 | 比例制容易两极：一部"还行"的片子也能拿高分 | 提醒自己：**比例 ≠ 强度**，本规范要评强度 |
| **Letterboxd** | 用户 5 星（半星粒度）；显示两位小数 | 基于用户打分平均；影迷样本偏艺术向 | 半星粒度接近本规范 0.5 档的直觉 |
| **TMDB** | 用户 1–10 分；同时有 popularity 热度指标 | 分数与热度分离，热度不等于质量 | 明确"热度不是评分维度" |
| **MyAnimeList** | 用户 1–10 分；显示两位小数 | 有 ranking 加权与样本量修正 | 借鉴"样本量修正" |
| **影展 / 评委会** | 奖项而非分数，强调艺术性 | 不覆盖商业类型片与娱乐性 | 只作为"艺术性维度"的参照 |

**结论**：把以上差异内化为三句话——

1. 平台分是**群体均值**，你的片单是**个人判断**，允许差异；
2. 样本量小的作品要**保守**，避免少数人打分带来的失真；
3. 区分**比例制**（好片比例高）与**强度制**（好到什么程度），本规范采用强度制。

## 四、简介撰写规范

### 4.1 长度与结构

- **长度**：中文 **80–150 字**；英文 **80–150 words**。
- **四段式结构**（可自然融合为一段，但信息必须齐全）：

| 段落 | 内容 | 占比 |
| --- | --- | --- |
| 钩子 | 一句话点出核心设定、悬念或冲突 | ≈ 20% |
| 展开 | 主要情节脉络、人物关系、关键选择 | ≈ 40% |
| 看点 | 导演 / 表演 / 类型特色 / 视听亮点 | ≈ 30% |
| 收束 | 一句气质或主题定位（不做推销） | ≈ 10% |

### 4.2 三套可复用模板

**模板 A｜剧情向**（适合剧情、传记、历史）
> [主角身份] 在 [处境] 之下，被卷入 [核心冲突]；随着 [关键事件] 的发生，[关系/信念] 逐渐 [变化]。[导演 / 表演 / 类型特色] 使这个故事 [气质定位]。

**模板 B｜悬念向**（适合悬疑、犯罪、惊悚）
> [一桩事件 / 一个谜题] 打破了 [平静状态]，[主角] 在追查过程中发现 [线索指向]；当 [真相逼近]，[代价] 也随之浮现。全片以 [节奏 / 视听] 维持张力。

**模板 C｜人物向**（适合成长、爱情、人物传记）
> [主角] 因 [契机] 走上 [道路]，在 [关系] 中经历了 [转折]；[结局之前的处境] 让他必须重新理解 [主题]。[表演 / 情绪基调] 是这部作品的核心。

### 4.3 语言要求

- 使用**陈述语气**，客观描述为主；评价性判断留给评分列。
- 语言流畅、有画面感，避免形容词堆砌。
- 全库句式要**有变化**，不要每部都以同一句式开头。
- 英文简介与中文一一对应，不要机翻堆词。
- 专有名词统一：系列名、导演与演员姓名跟随主流译名，全库保持一致。

### 4.4 禁忌清单

| 禁忌 | 原因 |
| --- | --- |
| 剧透关键转折 / 结局 / 真凶 | 破坏观看体验 |
| 直接复制百科、影评或平台简介 | 冗长、风格不统一、存在版权问题 |
| 只罗列演员表或主创名单 | 信息价值低 |
| 写「必看」「神作」「震撼」等推销语 | 主观评价属于评分列 |
| 以「本片讲述了」开头且篇篇相同 | 机械、可读性差 |
| 剧集写成整季剧情 | 只描述该条目对应的作品 |
| 使用未经核实的传闻或花絮 | 影响可信度 |

### 4.5 正反例（中文）

> **优秀（≈ 96 字）**
> 一名技艺高超的窃贼接到一桩不可能的任务：不是窃取财物，而是潜入他人梦境植入一个念头。随着梦境层层下探，现实与幻觉的边界逐渐崩塌，他必须先面对自己不愿触碰的往事。层层嵌套的结构与克制的情绪，让这部作品在商业外壳下保持清醒。

> **不合格**
> 本片由著名导演执导，众多明星联袂出演，讲述了主角完成任务的精彩历程，最后结局出人意料，非常值得一看。（堆砌评价、无信息量、末尾暗示反转）

### 4.6 Good / Bad examples (English)

> **Good (≈ 105 words)**
> A skilled thief is offered an impossible job: instead of stealing a secret, he must plant an idea inside someone's mind. As the team descends through nested dreams, the line between what is real and what is constructed begins to collapse — forcing him to confront a memory he has spent years avoiding. Tight structure and controlled emotion keep the film lucid beneath its blockbuster surface.

> **Bad**
> This film is directed by a famous director and features many stars. It tells the wonderful story of the protagonist completing a mission, and the ending is unexpected. Highly recommended. (Evaluation stacking, no information, spoiler hint.)

## 五、片单结构与字段定义

### 5.1 推荐表头

| 编号 | 标题 | 年份 | 分类 | 推荐评分 | 简介 |
| --- | --- | --- | --- | --- | --- |
| 001 | 盗梦空间 | 2010 | 科幻 | 9.39 | 一名技艺高超的窃贼接到一桩不可能的任务…… |

- 表头必须在**第一行**，数据从第二行开始。
- 列顺序可调整（按表头名识别）；「编号」亦可写作「片名」或「标题」。
- 标题列之后的**任意额外列**都会自动成为「标签组」（见第七章词表）。

### 5.2 字段定义

| 列名 | 必需 | 格式 | 说明 |
| --- | --- | --- | --- |
| 编号 / 标题 / 片名 | 是 | 文本，不含扩展名 | 与文件名匹配的主键；系统按「去噪标题 + 年份 + 词边界」模糊匹配，**不要**写画质后缀或网站水印 |
| 年份 | 建议 | 4 位数字 | 用于消歧同名影片（如 2021 与 1984 两版《沙丘》） |
| 分类 | 是 | 单一分类值 | 必须来自第六章的十类之一 |
| 推荐评分 | 是 | 0–10，两位小数 | 片单评分优先于数据源评分 |
| 简介 | 是 | 80–150 字 / words | 片单简介优先于数据源简介 |

### 5.3 常见错误

| 错误写法 | 后果 | 正确写法 |
| --- | --- | --- |
| `盗梦空间.2010.1080p.BluRay.x264` | 匹配噪声大，可能匹配失败 | `盗梦空间` |
| 同一影片出现两行 | 产生重复条目 | 每部作品只保留一行 |
| 评分写 `9` 或 `9.2分` | 无法解析为数值 | `9.00` / `9.20` |
| 分类写 `科幻/动作` | 分组混乱 | 主分类只填一个，其余进标签列 |
| 简介复制百科首段 | 冗长、剧透 | 按第四章模板重写 |
| 不想要数据源评分时填 `0` | 显示为 0 分 | 留空即可 |

## 六、分类体系

### 6.1 主分类（单选）

| 分类 | 适用范围 | 边界说明 |
| --- | --- | --- |
| 剧情 | 以人物、情感、社会议题为核心 | 传记、家庭、成长、历史题材归此类 |
| 动作 | 以动作场面与节奏驱动 | 含超级英雄、犯罪动作、武侠、谍战动作 |
| 科幻 | 以科学设定或未来想象为核心 | 太空歌剧、赛博朋克、硬科幻、时间旅行 |
| 喜剧 | 以幽默为主要目的 | 黑色幽默、讽刺喜剧归此类 |
| 爱情 | 以情感关系为主线 | 爱情喜剧按"主要诉求"二选一 |
| 悬疑 | 以谜题、推理、悬念驱动 | 含犯罪、推理、惊悚 |
| 恐怖 | 以恐惧体验为目的 | 含怪兽、灵异、心理恐怖 |
| 动画 | 以动画形式呈现 | 动画长片优先归此类，题材进标签 |
| 纪录片 | 非虚构记录 | 含自然、历史、人物纪实 |
| 其他 | 无法归入以上分类 | 实验影像、音乐现场、舞台实录 |

### 6.2 选择原则

1. **看主诉求，不看元素多少**：核心是情感关系就归「爱情」，科幻元素进标签。
2. **动画优先**：动画长片先进「动画」，再按题材打标签。
3. **不确定就用「其他」**，不要硬凑。
4. 分类只表达"怎么分组"，**细分一律交给标签列**。

### 7.2 地区（Region）

古代、近代、1920s、1930s、1940s、1950s、1960s、1970s、1980s、1990s、2000s、2010s、2020s、当代、未来、架空

## 八、质量检查清单

发布片单前逐项自查：

- [ ] 表头在第一行，包含 编号 / 标题 / 年份 / 分类 / 推荐评分 / 简介。
- [ ] 每部作品只有一行，无重复。
- [ ] 标题不含画质、编码、网站水印等噪声。
- [ ] 年份为 4 位数字或留空。
- [ ] 分类均来自第六章的十类之一，每行只有一个。
- [ ] 推荐评分为 0–10 的两位小数，**分布合理**（不是清一色高分）。
- [ ] 每个评分都能对应第三章的示例或 1.3 的锚点。
- [ ] 简介 80–150 字，无剧透、无推销语、句式不雷同。
- [ ] 标签列无空占位符（`无` / `N/A`），同义标签用词统一。
- [ ] 通读一遍，整体风格一致。

## 九、AI 生成指令模板

将下方整段（连同影片清单）交给 AI，可批量生成符合本规范的片单内容：

```text
请根据我提供的影片清单，按照以下要求生成影海片单 Excel 内容：

1. 先查询每部影片的准确信息（年份、类型、导演、主演、剧情梗概等）。
2. 从 剧情 / 动作 / 科幻 / 喜剧 / 爱情 / 悬疑 / 恐怖 / 动画 / 纪录片 / 其他 中选一个最匹配的主分类填入「分类」。
3. 撰写简介（中文 80–150 字，英文 80–150 words），不剧透关键转折与结局：
   结构 = 一句话钩子 + 主要情节脉络 + 看点亮点 + 一句气质定位；
   全片单句式要有变化，不要每部都用同一句式开头。
4. 推荐评分按十个维度加权计算（10 分制，两位小数），并在回答中简述依据：
   剧作 16% / 导演与调度 14% / 表演 14% / 摄影与美术 12% / 剪辑与节奏 10% /
   配乐与音效 10% / 主题与思想性 8% / 原创性 6% / 制作规格 5% / 系列定位与口碑 5%。
5. 评分须符合分档锚点：影史经典 9.20–9.60、年度最佳 8.50–9.15、类型标杆 7.80–8.45、
   合格商业片 7.00–7.75、有想法但失败 5.50–6.25；避免全部集中在 8 分以上，
   冷门作品（样本少）请保守给分。
6. 额外标签（主题 / 地区 / 年代 / 系列 / 类型元素 / 氛围 / 看点）用「、」分隔，
   单格不超过 5 个值；无内容留空，不要写「无」或「N/A」。
7. 若一次提供多部影片，请逐一处理，保持格式与语气统一。

【Excel 表头】编号	标题	年份	分类	推荐评分	简介	主题	地区	系列
```

**输出要求**：直接给出可粘贴进 Excel 的制表符分隔文本（每部一行），不要额外解释或总结。

## 十、使用建议

1. **先小批试跑**：选 5–10 部熟悉的影片按本规范打分，检查档位是否符合直觉，再批量处理。
2. **权重可个性化**：把 1.1 的权重调成自己的偏好（例如表演 +5%、制作规格 −5%），但务必**整库统一**。
3. **AI 只做初稿**：AI 生成的评分与简介应视为草稿，尤其是评分，建议人工复核区间是否合理。
4. **善用锚点**：每当不确定时，拿 1.3 的锚点作品做横向比较，比"凭感觉"稳定得多。
5. **长期维护**：影库越大，对类型标杆、系列口碑与工业完成度的判断越准，评分会自然趋稳。
6. **不满意就改**：这份规范是工具而不是枷锁；先保证一致性，再逐步逼近你自己的审美标准。
