# 通用影片评分与简介规范

> 本规范是影海片单（Excel）的**唯一权威撰写标准**，用于统一每部影片的分类、评分与简介风格。
> 既可直接阅读，也可整份粘贴给 AI，让它按同一口径批量生成 / 校对片单。
>
> 设计取向：**去个人偏好、可复现、可校准、覆盖主流与类型片（含情色、猎奇、三级、exploitation）**。
> 评分不是"感觉给个数"，而是按固定维度加权计算；简介以结构化、可读、信息完整为优先，允许参考百科与公开资料梳理剧情主线（禁止大段原文复制与关键结局剧透）。
> 影库越大，评分越稳定、越贴近你的真实观影判断。

## 一、评分标准

### 1.1 评分维度与建议权重（10 分制，保留两位小数）

| 维度 | 建议权重 | 观察点（打分依据） |
| --- | --- | --- |
| 剧作 / 编剧 | 15% | 结构完整性、逻辑自洽、人物弧光、对白质量、是否注水、情节推进是否自然、类型叙事是否有效 |
| 导演与调度 | 14% | 叙事把控、场面调度、镜头语言、作者性、整体完成度、类型掌控力、氛围营造 |
| 表演 | 13% | 主角与配角的可信度、层次感、情绪张力、群戏协调、角色塑造是否立体、情色场面中的自然度与张力 |
| 摄影与美术 | 12% | 构图、光影、色彩、置景与服化道的完成度、视觉风格统一性、情色/猎奇场面的视觉呈现 |
| 剪辑与节奏 | 10% | 信息密度、张弛控制、是否拖沓或跳跃、章节结构、观感流畅度、类型节奏把控 |
| 配乐与音效 | 9% | 主题旋律、音画配合、混音层次、声音设计、氛围营造效果 |
| 主题与思想性 | 8% | 议题深度、表达克制、是否留下余味与讨论空间、价值观是否清晰、对欲望/暴力/社会议题的处理 |
| 原创性与差异化 | 7% | 设定、视角、结构的独特性，是否避免同质化，类型创新程度，猎奇/情色表达的新鲜感 |
| 制作规格与工业完成度 | 6% | 特效、动作设计、类型场面调度、成片质感、预算与呈现匹配度、低成本作品的完成度 |
| 系列定位与口碑延续 / 类型标杆度 | 6% | 是否为经典系列、续作与前作的一致性、系列内相对位置、在同类类型片中的口碑与影响 |

**权重说明**

- 上表为**推荐默认值**，可按个人偏好调整（例如更看重表演与剧作，或更看重视听与场面）。调整后权重之和必须为 100%，整库统一。
- 每项先独立打分，再加权合成；**不允许先给总分再倒推分项**。
- **类型适配原则**：
  - 主流商业 / 艺术片：按默认权重。
  - 低成本三级 / 情色 / 猎奇 / exploitation：制作规格与工业完成度、原创性可适当放宽基准，优先与**同类作品横向对比**。
  - 情色片额外关注：情色场面的叙事功能、演员自然度、视觉美感 vs 纯猎奇堆砌。
  - 恐怖 / 悬疑：额外关注氛围与节奏控制。

**计算公式**

```
总分 = Σ(各维度得分 × 对应权重)
保留两位小数（第三位四舍五入）
```

### 1.3 基准锚点（打分前先校准）

| 锚点类型 | 参考分值 | 用途 |
| --- | --- | --- |
| 公认影史经典 | 9.20 – 9.60 | 上限参照；不是每个年代都有 |
| 年度最佳 / 三大影展获奖级 | 8.50 – 9.15 | 优秀作品的天花板 |
| 类型片标杆（该类型最好的几部） | 7.80 – 8.45 | "这一类型能到什么程度" |
| 品质在线的院线商业片 | 7.00 – 7.75 | 大多数好片的落点 |
| 合格的流媒体 / 类型快消品 | 6.30 – 6.95 | 能看，但不值得专门找 |
| 有想法但执行失败 | 5.50 – 6.25 | 常见于野心过大的作品 |
| 低成本三级 / 情色 / 猎奇合格线 | 5.80 – 6.80 | 同类横向对比的主流落点 |
| 制作事故级 | ≤ 4.45 | 极少出现 |

**类型专属锚点示例**（供参考，非强制）

| 类型 | 高锚（优秀） | 中锚（良好） | 低锚（及格） |
| --- | --- | --- | --- |
| 情色 / 三级 | 玉蒲团之偷情宝鉴级（6.7+） | 多数香港三级合格作（6.0–6.5） | 纯堆砌无叙事（5.0–5.8） |
| 猎奇 / exploitation | 八仙饭店之人肉叉烧包级（7.5+） | 有风格有完成度的猎奇（6.2–6.8） | 粗糙猎奇（5.0–5.8） |
| 恐怖 | 经典港恐 / 亚洲恐怖标杆（7.8+） | 合格氛围恐怖（6.5–7.2） | 惊吓堆砌（5.5–6.2） |
| 犯罪 / 悬疑 | 经典港产犯罪（7.8+） | 扎实推理或犯罪（6.8–7.5） | 套路化（5.8–6.5） |

### 1.4 评分流程（五步法）

1. **对锚**：想清"它比哪个锚点更好/更差"，先定大致区间（如 7.8–8.5 或 5.8–6.5）。优先使用类型专属锚点。
2. **分项**：按 1.1 的十个维度逐项打分，每项写下至少一个具体依据（可参考公开资料与观影感受）。
3. **加权**：按公式合成，得到两位小数。
4. **回查**：用 1.6 的三问自检；若有答不上来的，回到第 2 步。
5. **落笔**：写入「推荐评分」列，并在需要时保留一句依据备注（可写在自己的备忘录，不必进片单）。

### 1.5 评分纪律

1. **不扎堆**：若 80% 的作品都在 8 分以上，说明标尺失效，需重新校准。
2. **不趋同**：不照抄 IMDb / 豆瓣；那是群体均值，片单是你的私人评价，允许差异但必须能自圆其说。
3. **不因题材加分**：喜欢某类型 ≠ 每个条目都该高分。
4. **不看热度**：票房、话题度、明星阵容、宣发规模都不构成加分项。
5. **不因单点封神**：一个惊艳镜头或一场大胆情色场面不足以撑起高分，必须整体成立。
6. **冷门作品保守**：样本极少的作品建议收敛到 5.5–7.5 区间，避免"小众滤镜"。
7. **复评有度**：重看后可修改，但同一部片短期内不要反复震荡。
8. **口径一致**：同一批片单内不要混用两套标准。
9. **类型适配强制**：对三级片、情色、猎奇、低成本作品，**必须**与同类横向对比，禁止用主流大片标尺强行压分或抬分。
10. **情色特殊纪律**：情色场面的存在本身不加分也不减分；只评价其是否服务于叙事、是否完成度高、是否有风格。

### 1.6 评分自检三问

1. 我给的分数，能否说出**至少两个具体依据**？
2. 同类型里更好的作品是否比它高？更差的是否比它低？
3. 若别人问"为什么是这个分"，我能否在**两句话内**解释清楚？

三问有一问答不上，回去重新打分。

### 1.7 常见评分偏差与矫正

| 偏差 | 表现 | 矫正方法 |
| --- | --- | --- |
| 评分通胀 | 全线 8 分以上，失去区分度 | 强制使用 1.2 的细档；回顾自己的低分作品是否被高估 |
| 分数紧缩 | 大多落在 6–7 分，好片也平平 | 允许 9 分以上存在，重看年度最佳与类型标杆 |
| 情感加分 | 观影时情绪好就高分 | 冷静 24 小时后再定档 |
| 题材滤镜 | 喜欢的类型一律偏高 | 只按维度打分，题材本身不加权 |
| 明星加分 | 因演员/导演名气给分 | 名气只影响"是否观看"，不影响"作品质量" |
| 从众 | 直接抄平台均分 | 平台分只用于校准区间，不用于最终分数 |
| 报复性低分 | 期待落差导致过低 | 与同类型作品横向比较后再定档 |
| 标尺错位 | 用大片标准评价低成本三级片 | 建立同类锚点，允许 5–7 分区间成为主流落点 |
| 情色偏见 | 因情色内容自动低分或高分 | 只评价完成度与叙事功能，内容本身中立 |

## 二、全网评分体系对照与借鉴

各平台的评分口径差异很大，理解它们有助于校准自己的标尺（**仅用于校准，不用于照抄**）。

| 平台 | 原始口径 | 特点与局限 | 映射到本规范 |
| --- | --- | --- | --- |
| **IMDb** | 用户 1–10 分；显示一位小数 | 采用**加权平均**，过滤异常投票；新片、冷门片票数少时分数波动大 | 借鉴其"票数少则保守"的思路；建议冷门片收敛在 5.5–7.5 |
| **豆瓣** | 用户 1–5 星，换算为 2–10 分 | 加权平均 + 异常账号过滤；文艺片与国产片样本偏多，类型偏见明显 | 只用于区间校准；不要直接搬分数 |
| **Metacritic** | Metascore 0–100（媒体加权）；User Score 0–10 | 专业与大众两套分数分离 | 借鉴"专业视角 vs 大众视角可分离" |
| **Rotten Tomatoes** | 新鲜度 = 正面评价**比例**；另有平均分 | 比例制容易两极 | 提醒自己：**比例 ≠ 强度**，本规范要评强度 |
| **Letterboxd** | 用户 5 星（半星粒度） | 影迷样本偏艺术向 | 半星粒度接近本规范 0.5 档的直觉 |
| **TMDB** | 用户 1–10 分；同时有 popularity | 分数与热度分离 | 明确"热度不是评分维度" |
| **MyAnimeList** | 用户 1–10 分 | 有 ranking 加权与样本量修正 | 借鉴"样本量修正" |
| **影展 / 评委会** | 奖项而非分数，强调艺术性 | 不覆盖商业类型片与娱乐性 | 只作为"艺术性维度"的参照 |
| **香港三级片口碑** | 多为影迷私下讨论与影评 | 重视完成度、风格、演员表现与猎奇程度 | 作为情色 / 猎奇类锚点的重要参考 |

**结论**：

1. 平台分是**群体均值**，你的片单是**个人判断**，允许差异；
2. 样本量小的作品要**保守**；
3. 区分**比例制**与**强度制**，本规范采用强度制；
4. 对类型片尤其是三级 / 情色 / 猎奇，优先参考同类影迷讨论与横向对比。

## 四、简介撰写规范

### 4.1 长度与结构

- **长度**：中文 **80–180 字**（允许根据信息量适度放宽）；英文 **80–180 words**。
- **四段式结构**（可自然融合为一段，但信息必须齐全）：

| 段落 | 内容 | 占比 |
| --- | --- | --- |
| 钩子 | 一句话点出核心设定、悬念或冲突 | ≈ 20% |
| 展开 | 主要情节脉络、人物关系、关键选择（可参考百科公开剧情，允许介绍主线过程） | ≈ 40% |
| 看点 | 导演 / 表演 / 类型特色 / 视听亮点 / 情色或猎奇表达特色 | ≈ 30% |
| 收束 | 一句气质或主题定位（不做推销） | ≈ 10% |

### 4.2 可复用模板（增加情色 / 猎奇向）

**模板 A｜剧情向**
> [主角身份] 在 [处境] 之下，被卷入 [核心冲突]；随着 [关键事件] 的发生，[关系/信念] 逐渐 [变化]。[导演 / 表演 / 类型特色] 使这个故事 [气质定位]。

**模板 B｜悬念 / 犯罪向**
> [一桩事件 / 一个谜题] 打破了 [平静状态]，[主角] 在追查过程中发现 [线索指向]；当 [真相逼近]，[代价] 也随之浮现。全片以 [节奏 / 视听] 维持张力。

**模板 C｜人物向**
> [主角] 因 [契机] 走上 [道路]，在 [关系] 中经历了 [转折]；[结局之前的处境] 让他必须重新理解 [主题]。[表演 / 情绪基调] 是这部作品的核心。

**模板 D｜情色 / 三级向**
> [主角] 在 [古装 / 现代 / 特定环境] 中陷入 [欲望 / 权力 / 纠葛] 的漩涡，与 [关键人物] 展开一系列情欲纠葛。影片以 [视觉风格 / 场面调度] 呈现欲望与人性，整体气质偏向 [艳情 / 猎奇 / 伦理]。

**模板 E｜猎奇 / exploitation 向**
> [真实事件 / 极端设定] 成为故事起点，[主角] 在 [暴力 / 欲望 / 社会边缘] 中不断沉沦或反击。影片以直白甚至残酷的方式呈现 [核心元素]，风格强烈而极端。

### 4.3 语言要求

- 使用**陈述语气**，客观描述为主；评价性判断留给评分列。
- 语言流畅、有画面感，避免形容词堆砌。
- 全库句式要**有变化**，不要每部都以同一句式开头。
- 专有名词统一：系列名、导演与演员姓名跟随主流译名。
- **允许参考百科、IMDb、豆瓣、TMDB 等公开资料**梳理剧情主线，但必须改写为规范结构，禁止大段原文复制。
- 情色 / 猎奇内容可用中性词汇描述（情欲纠葛、欲望漩涡、极端场面等），避免低俗堆砌。

### 4.4 禁忌清单

| 禁忌 | 原因 |
| --- | --- |
| 直接复制百科、影评或平台简介原文 | 冗长、风格不统一、存在版权问题 |
| 只罗列演员表或主创名单 | 信息价值低 |
| 写「必看」「神作」「震撼」「超级色情」等推销语 | 主观评价属于评分列 |
| 以「本片讲述了」开头且篇篇相同 | 机械、可读性差 |
| 剧集写成整季剧情 | 只描述该条目对应的作品 |
| 使用未经核实的传闻或花絮 | 影响可信度 |
| 关键结局、真凶身份的明确剧透 | 破坏观看体验（主线过程可写，结局与核心反转仍建议保留） |
| 低俗、露骨到令人不适的细节堆砌 | 简介应保持可读性与专业感 |

### 4.5 正反例

> **优秀（情色向，≈ 120 字）**
> 明代才子未央生自恃才貌，追求人间极乐，却因与宁王结怨落入圈套。妻子铁玉香舍命相救，故事在情欲与权谋之间展开。全片以大胆的古装情色场面与 3D 技术呈现欲望世界，视觉直接，气质偏向商业化艳情。

> **优秀（猎奇向，≈ 110 字）**
> 澳门海滩发现人体残肢，警方追查八仙饭店郑氏一家失踪案，矛头指向店主张志恒。调查过程中人与人之间的猜忌与暴力交织。黄秋生的表演充满压迫感，影片以真实案件为蓝本，营造出阴冷残酷的氛围。

> **不合格**
> 本片由著名导演执导，众多明星联袂出演，讲述了主角完成任务的精彩历程，最后结局出人意料，非常值得一看。（堆砌评价、无信息量、末尾暗示反转）

## 五、片单结构与字段定义

### 5.1 推荐表头

| 编号 | 标题 | 年份 | 分类 | 推荐评分 | 简介 |
| --- | --- | --- | --- | --- | --- |
| 001 | 盗梦空间 | 2010 | 科幻 | 9.38 | 一名技艺高超的窃贼接到一桩不可能的任务…… |

- 表头必须在**第一行**，数据从第二行开始。
- 列顺序可调整（按表头名识别）。
- 标题列之后的**任意额外列**都会自动成为「标签组」。

### 5.2 字段定义

| 列名 | 必需 | 格式 | 说明 |
| --- | --- | --- | --- |
| 编号 / 标题 / 片名 | 是 | 文本，不含扩展名 | 与文件名匹配的主键；不要写画质后缀或网站水印 |
| 年份 | 建议 | 4 位数字 | 用于消歧同名影片 |
| 分类 | 是 | 单一分类值 | 必须来自第六章的十五类之一 |
| 推荐评分 | 是 | 0–10，两位小数 | 片单评分优先于数据源评分 |
| 简介 | 是 | 80–180 字 | 片单简介优先于数据源简介 |

### 5.3 常见错误

| 错误写法 | 后果 | 正确写法 |
| --- | --- | --- |
| 标题含画质 / 编码 / 水印 | 匹配失败 | 干净标题 |
| 同一影片两行 | 重复 | 每部只保留一行 |
| 评分写 `9` 或 `9.2分` | 无法解析 | `9.00` / `9.20` |
| 分类写多个 | 分组混乱 | 主分类只填一个，其余进标签 |
| 简介直接复制百科 | 风格不统一 | 按第四章模板改写 |
| 情色片分类填「其他」导致筛选困难 | 不便 | 优先使用「情色」主分类 |

## 六、分类体系

### 6.1 主分类（单选，共 15 类）

| 分类 | 适用范围 | 边界说明 |
| --- | --- | --- |
| 剧情 | 以人物、情感、社会议题为核心 | 传记、家庭、成长、伦理、社会写实 |
| 动作 | 以动作场面与节奏驱动 | 超级英雄、犯罪动作、武打、谍战动作 |
| 科幻 | 以科学设定或未来想象为核心 | 太空歌剧、赛博朋克、硬科幻、时间旅行 |
| 喜剧 | 以幽默为主要目的 | 黑色幽默、讽刺喜剧、无厘头 |
| 爱情 | 以情感关系为主线 | 爱情喜剧按主要诉求二选一 |
| 悬疑 | 以谜题、推理、悬念驱动 | 含犯罪推理、惊悚悬疑 |
| 恐怖 | 以恐惧体验为目的 | 含灵异、心理恐怖、怪兽、gore |
| 动画 | 以动画形式呈现 | 动画长片优先归此类，题材进标签 |
| 纪录片 | 非虚构记录 | 含自然、历史、人物纪实 |
| **情色** | **以情欲、性爱、身体欲望为核心驱动** | **香港三级、情色伦理、艳情古装、erotica；多数玉蒲团 / 金瓶梅 / 聊斋艳谭系列归此类** |
| 犯罪 | 以犯罪过程、黑道、执法为核心 | 黑帮、警匪、真实犯罪改编 |
| 奇幻 | 以超自然、神话、魔法为核心 | 聊斋鬼怪（非纯情色）、奇幻冒险 |
| 历史 | 以真实历史事件或人物为背景 | 历史正剧、历史传奇 |
| 武侠 | 以江湖、侠义、武功为核心 | 传统武侠、新派武侠 |
| 其他 | 无法归入以上分类 | 实验影像、音乐现场、舞台实录、极端猎奇无法归类者 |

### 6.2 选择原则

1. **看主诉求，不看元素多少**：核心是情欲纠葛就归「情色」，即使有鬼怪或古装元素；核心是恐惧就归「恐怖」。
2. **情色优先于剧情**：明确以性爱场面与欲望驱动的作品，优先选「情色」，而不是笼统归「剧情」。
3. **动画优先**：动画长片先进「动画」。
4. **不确定就用「其他」**，不要硬凑。
5. 分类只表达"怎么分组"，**细分（如三级、猎奇、gore、SM 等）一律交给标签列**。

### 6.3 常见归类速查

| 作品类型 | 推荐主分类 | 常见标签补充 |
| --- | --- | --- |
| 玉蒲团 / 金瓶梅 / 聊斋艳谭系列 | 情色 | 古装、艳情、三级 |
| 八仙饭店之人肉叉烧包 | 犯罪 或 悬疑 | 真实事件改编、猎奇、gore |
| 满清十大酷刑系列 | 情色 或 历史 | 酷刑、猎奇、三级 |
| 港产灵异 / 画皮类 | 恐怖 或 奇幻 | 鬼怪、聊斋 |
| 纯堆砌性爱无叙事 | 情色 | 三级、猎奇 |
| 实验 / 极端无法归类 | 其他 | 实验、猎奇 |

## 十、使用建议

1. **先小批试跑**：选 5–10 部熟悉的影片（含主流 + 三级 / 情色）按本规范打分，检查档位是否符合直觉，再批量处理。
2. **权重可个性化**：把 1.1 的权重调成自己的偏好，但务必**整库统一**。
3. **AI 只做初稿**：AI 生成的评分与简介应视为草稿，尤其是评分，建议人工复核区间是否合理。
4. **善用锚点**：不确定时，拿 1.3 的锚点（含类型专属）做横向比较。
5. **长期维护**：影库越大，对类型标杆、系列口碑与工业完成度的判断越准，评分会自然趋稳。
6. **三级 / 情色 / 猎奇特别提示**：
   - 主分类优先用「情色」而非「其他」。
   - 评分以同类对比为主，允许 5–7 分成为主流区间。
   - 简介可用中性词汇描述欲望与极端场面，保持专业可读。
7. **不满意就改**：这份规范是工具而不是枷锁；先保证一致性，再逐步逼近你自己的审美标准。
